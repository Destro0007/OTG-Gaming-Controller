# OTG Gaming Controller V1.0

Native Android utility for connected input-device diagnostics and local visual profile management.

Features: connected input inventory, foreground keyboard event tester, mouse/touch test area, local profiles, sensitivity reference value, and visual layout markers.

Limitations: this is not a game keymapper. It does not inject touch events into other apps, automate gameplay, bypass anti-cheat, or change game settings. Each Android app/game decides whether external input is supported.

GitHub Actions builds a debug APK on pushes to `main` and manual workflow dispatch. Download the `otg-gaming-controller-debug` artifact from a successful run.
